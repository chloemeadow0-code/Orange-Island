# 橘子岛 UI 0.4 开发交付对照表

## 实施边界

- 保留原 App 页面结构、纵向顺序、功能名称、导航与交互。
- HTML 是视觉参考，不要求开发者复制网页实现方式。
- Compose 侧只需要迁移颜色、尺寸、边框、阴影、贴图位置与图片资源。
- 装饰图片均应设置为不接收点击，不改变原组件可点击区域。

## 页面与 Compose 组件

| HTML | 原 App 组件 | 本轮只改 |
|---|---|---|
| `index.html .chat-header` | `ChatTopBar` | 背景、圆角、按钮材质、品牌小图 |
| `index.html .chat-empty-state` | 空会话 / 初始聊天状态 | 水彩橘子船、原欢迎文案与留白；不新增按钮 |
| `index.html .chat-scroll` | `MessageList` | 背景空气感、间距微调 |
| `index.html .message-bubble` | `AssistantMessageContent` / `UserMessageBubble` | 边框、圆角、底色、角落贴图 |
| `index.html .composer-area` | `ChatBottomBar` | 输入框边框、按钮样式、模型胶囊 |
| `settings.html .settings-header` | `SettingsScaffold` | 返回按钮、标题、右上橘枝贴图 |
| `settings.html .setting-row` | 设置列表行 | 卡片边框、阴影、独立图标 |
| `settings.html .settings-scroll::after` | 设置页背景层 | 底部小岛贴图 |
| `components.html` | 视觉规范 | 颜色、图标与资源映射参考 |

`index.html` 右侧的“初始空页面 / 已有对话”切换仅供评审对照，不属于正式 App 功能。开发时根据原 App 是否已有消息显示对应状态即可。

## 装饰资源

| 文件 | 使用位置 | 建议 |
|---|---|---|
| `assets/decorations/orange-boat-transparent.png` | 助手气泡角落、欢迎或空状态 | 正式透明资源，只取边角，不遮挡正文 |
| `assets/decorations/orange-branch.png` | 设置页右上角 | 低透明度、忽略点击 |
| `assets/decorations/cottage-island.png` | 设置页底部 | 作为背景层，不挤占列表 |
| `assets/decorations/orange-sprout-corner.png` | 长消息气泡右下角 | 允许轻微越过卡片边缘 |
| `assets/decorations/orange-wave-corner.png` | 空状态或次级卡片边角 | 低频使用 |

## 核心视觉值

| Token | 默认值 |
|---|---|
| Brand Orange | `#F28A34` |
| Leaf Green | `#78966C` |
| Cream Background | `#FFFBF5` |
| Paper Surface | `#FFFEFB` |
| Main Text | `#3D2F27` |
| Muted Text | `#917F72` |
| Main Radius | `24px`，Compose 可对应 `24.dp` |

开发者以 `components.html` 中的实机比例预览为视觉准绳；如果 HTML 的装饰与可读性冲突，优先保证原 App 的内容与点击区域。
