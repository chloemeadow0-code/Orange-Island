橘子岛 UI Playground v0.4

打开方式
1. 双击 index.html，浏览器会直接打开聊天页。
2. 左侧可切换“聊天页 / 设置页 / 组件展示”。
3. 右侧“视觉调节器”可以换预设、品牌橘、叶片绿、圆角和内容密度。
4. 调整结果会保存在当前浏览器中，并在三个页面之间同步。

聊天页状态
- 默认打开“初始空页面”，中央使用水彩橘子船和原文案“欢迎使用 橘子岛。”。
- 右侧调节器可切换到“已有对话”，用于检查气泡和长文本。
- 这个切换器只属于 HTML 试玩原型，开发者不需要把它搬进 App。
- 在初始空页面直接发送消息，会自动进入已有对话状态。

本版硬规则
- 不修改原 App 的功能名称、分类顺序、页面跳转与交互逻辑。
- 原来上下排列的内容仍然上下排列，不改成宫格或左右双栏。
- 仅调整图标、颜色、背景、贴图、边框、圆角、阴影和组件尺寸。

可以试玩的内容
- 聊天页可以展开工具栏、输入消息并发送。
- 设置页的开关和列表可以点击。
- 组件页集中展示配色、独立水彩图标、按钮、卡片、气泡、布局边界和资源对应关系。

文件说明
- index.html：聊天页与默认入口
- settings.html：设置页
- components.html：组件展示与开发交付对照页
- styles.css：全部视觉样式
- app.js：交互与调节器
- assets/icons：按最新 APK 功能命名的 36 张透明水彩图标
- assets/decorations：橘枝、小岛、气泡角落等透明水彩贴图
- assets/asset-manifest.csv：图片文件、功能名称与 Compose 组件对照
- assets/orange-boat-watercolor.png：用户选定的橘子船原图
- assets/decorations/orange-boat-transparent.png：可直接放入 App 的透明橘子船
- 开发交付对照表.md：HTML 与 Android Compose 组件、图片文件的对应关系

这是本地视觉原型，不会联网，也不会调用真实模型或 API。
