# バージョン情報

アプリのバージョン、アップデート、ドキュメント設定、およびリンク。

## アプリ情報

| 項目 | 説明 |
|-------|-------------|
| **開発者** | Newo Ether |
| **バージョン** | 現在のバージョン名とビルドコードを表示 |

---

## アップデート

### アップデートを確認

**アップデートを確認** をタップして、GitHub の最新リリースを照会します。橘子岛 はインストールされているバージョンを最新リリースと比較し、結果を表示します：

- **アップデートあり** — GitHub により新しいバージョンが公開されています
- **最新です** — 最新リリースを実行中です

### 自動アップデート確認

有効にすると、橘子岛 はバックグラウンドで定期的に新しいリリースを確認します。自動確認を無効にするには、このトグルをオフにします。

---

## ドキュメント

### ドキュメントリンクを表示

設定サブページに表示される **フローティングヘルプボタン**（FAB）を制御します。有効にすると、:material-help-circle: ボタンが関連するユーザーマニュアルページにリンクします。

ドキュメント FAB のないよりクリーンなインターフェースを希望する場合は、このトグルをオフにしてください。

---

## リンク

| リンク | 宛先 |
|------|-------------|
| **GitHub** | 橘子岛 ソースコードリポジトリ |
| **Issue トラッカー** | バグの報告や機能のリクエスト |
| **貢献** | プルリクエストを開く |
| **プライバシーポリシー** | 橘子岛 プライバシーポリシー |

---

## 評価

内蔵のフィードバックフォームでアプリを評価し、コメントを送信できます。あなたのフィードバックは 橘子岛 の改善に役立ちます。

---

## クラッシュログ

橘子岛 でエラーが発生した場合、**設定 → バージョン情報 → クラッシュログ** からクラッシュログを表示できます。ログは等幅フォントのダイアログに表示され、**コピー** ボタンでバグ報告時に診断情報を共有できます。
