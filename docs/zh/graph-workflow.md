# 图谱工作流使用指南

图谱工作流（Graph Workflow）是橘子岛的高级自动化功能，用"节点+连线"的方式把一系列动作串起来执行。你可以把它理解成一个简单的流程图：每个节点做一件事，连线决定下一步去哪。

---

## 一、创建工作流

1. 打开 **设置 → 工作流**
2. 点右下角 **+ 新建图谱工作流**
3. 弹出模板选择：
   - **顺序执行** — 先做什么、再做什么，最简单
   - **条件分支** — 如果满足条件走 A 路，不满足走 B 路
   - **提取数据** — 从文本里抠出想要的内容，传给下一步用
   - **空白** — 从零开始自己搭
4. 选一个模板，输入名称，点**创建**

> 建议第一次用先选**顺序执行**试试手感。

## 二、认识节点

每个卡片就是一个节点，点卡片右边的小箭头可以展开编辑。

### 1. 开始节点
整个流程的入口。决定这个工作流什么时候触发：
- **手动** — 你点"运行"才执行
- **打开应用** — 打开某个 App 时触发
- **接口** — 外部程序调 API 时触发
- **定时** — 按设定的时间间隔自动跑
- **意图** — 收到特定系统广播时触发
- **语音** — 语音指令触发

### 2. 动作节点
真正干活的地方。需要填两个东西：
- **工具名** — 比如 `web_search`（网页搜索）、`send_notification`（发通知）等
- **参数** — 点"添加参数"可以给工具传参
  - **文本** — 直接写死的内容，比如搜索关键词 `"新闻"`
  - **引用** — 引用上游某个节点的输出结果，实现数据传递

### 3. 分支节点
做判断用。左边和右边各填一个值，中间选一个比较方式：
- 等于 / 不等于
- 大于 / 小于 / 大于等于 / 小于等于
- 包含 / 不包含
- 在列表里 / 不在列表里

判断结果为**真**或**假**，分别走不同的连线。

### 4. 合并节点
多个分支汇合时用。合并方式：
- **全部满足** — 所有前置条件都为真才继续
- **任一满足** — 只要有一个为真就继续

### 5. 转换节点
对文本进行加工处理。支持 7 种操作：
- **固定值** — 输出一个写死的字符串
- **正则提取** — 用正则表达式从文本里匹配内容（可指定捕获组和默认值）
- **JSON 路径** — 从 JSON 字符串里按路径取值
- **切片** — 截取字符串的一部分（起始位置 + 长度）
- **拼接** — 把多个字符串连起来
- **随机整数** — 生成指定范围内的随机数
- **随机文本** — 生成指定长度和字符集的随机字符串

## 三、添加和编辑连线

节点卡片下方有个 **"添加连线"** 按钮。一条连线需要设置：
- **来源** — 从哪个节点出发
- **目标** — 到哪个节点去
- **守卫** — 什么条件下这条连线才生效
  - **无** — 无条件，直接走
  - **成功** — 来源节点执行成功才走
  - **失败** — 来源节点执行失败才走
  - **为真** — 来源节点输出布尔真才走
  - **为假** — 来源节点输出布尔假才走
  - **正则匹配** — 来源节点输出匹配指定正则才走

> 分支节点后面通常挂两条连线，一条守卫设为"为真"，另一条设为"为假"。

## 四、数据怎么传（引用机制）

动作节点的参数可以设为**引用**模式。选择后下拉框会列出所有节点的 ID，选中某个节点，运行时就会自动把那个节点的输出结果填到这里。

比如：
1. 转换节点用正则提取出一串数字
2. 动作节点把查询参数设为**引用** → 指向那个转换节点
3. 运行时，动作节点拿到的就是提取出来的数字

---

## 五、运行工作流

编辑完点右上角 **保存**，回到列表：
- 点卡片上的 **▶ 播放按钮** 手动运行
- 列表里会显示运行状态（✓ 成功 / ✗ 失败 / … 运行中）

如果开启了触发器（比如定时），满足条件时会自动执行。

## 六、快速上手示例

### 示例 A：搜新闻并通知我（顺序执行）
1. 新建 → 选**顺序执行**模板
2. 开始节点保持"手动"触发
3. 第二个节点（搜索）工具名填 `web_search`，添加参数 `query` = `"新闻"`
4. 第三个节点（通知）工具名填 `send_notification`，添加参数 `title` = `"搜完了"`
5. 保存 → 运行

### 示例 B：满足条件才执行（条件分支）
1. 新建 → 选**条件分支**模板
2. 分支节点的左值填 `"是"`，比较方式选"等于"，右值填 `"是"`
3. 真分支连到"执行"动作，假分支连到"跳过"动作
4. 保存 → 运行

### 示例 C：提取数据再用（提取数据）
1. 新建 → 选**提取数据**模板
2. 转换节点操作选"正则提取"，正则表达式填 `\d+`（匹配数字）
3. 后面的动作节点参数设为**引用** → 指向转换节点
4. 保存 → 运行，动作节点就能拿到提取到的数字

## 七、常见问题

**Q：为什么我的动作节点没有参数？**  
A：点卡片展开，在"参数"区域点"添加参数"即可。参数名和值都要填。

**Q：引用模式下拉框为什么是空的？**  
A：需要先创建其他节点，有节点才能引用。

**Q：连线守卫的"正则匹配"怎么用？**  
A：选"正则匹配"后会出现一个输入框，填正则表达式。来源节点的输出如果匹配这个正则，这条连线就会生效。

**Q：工作流报错怎么办？**  
A：长按工作流卡片 → 选"日志"，可以看到每次运行的详细记录和错误信息。
