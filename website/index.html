🔑 BYOK

自备 API Key，无中间商，无订阅费，直接连接 OpenAI、Claude、Gemini、DeepSeek 等。

🌳 非线性对话

树状消息结构，支持分支、编辑、重新生成，保留每一个思路。

🛠️ 代理工具

联网搜索、代码执行、图像生成、记忆文件、RAG 搜索、远程 Shell。

📱 本地模型

内置 llama.cpp，可在设备上离线运行 GGUF 模型。

🔒 数据本地

聊天记录、API Key、设置全部存储在设备本地，不上传官方服务器。

⚡ 工作流

按时间、通知、地理围栏等事件触发自动化任务。

  2. 进入 审核答题，输入 QQ 号并回答所有题目。
  3. 全部答对即可获取入群方式与使用资格。
